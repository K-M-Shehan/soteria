# Wi‑Fi & Blynk notes
This folder contains shared Wi‑Fi and Blynk configuration used by both the main unit and sub units.

See `BLYNK_SETUP.md` for instructions on how to configure the Blynk app and populate credentials.

Do not commit real Wi‑Fi SSIDs, passwords, or the Blynk auth token to version control. Use `ssid_example.h` instead and add the real `ssid.h` to `.gitignore`.
